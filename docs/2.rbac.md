# Project Demonstration Notes: Role-Based Access Control (RBAC)

## Key Feature: Role-Based Access Control (RBAC) using Servlet Filter

*   **Demonstration:** Show how different users (Admin, Teacher, Parent, Student) have access to different pages and functionalities. Attempt to access a restricted page with an unauthorized user to show the `access_denied.jsp` page.
*   **Underlying Mechanism:** The application uses a Java Servlet Filter (`AuthFilter.java`) to centralize authentication and authorization logic. This filter intercepts all requests to `.jsp` pages, checks the user's session for `userId` and `userRole`, and redirects unauthorized users to `login.jsp` or `access_denied.jsp`.

#### Technical Details: `AuthFilter.java` and `web.xml`

**`AuthFilter.java` (Simplified Snippet):**

```java
package com.academic.filters;

import jakarta.servlet.*;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.servlet.http.HttpSession;
import java.io.IOException;
import java.util.Arrays;
import java.util.List;

public class AuthFilter implements Filter {

    private static final List<String> EXCLUDED_URLS = Arrays.asList(
        "/login.jsp", "/login_process.jsp", "/register.jsp", 
        "/register_process.jsp", "/forgot_password.jsp", 
        "/forgot_password_process.jsp", "/access_denied.jsp"
    );

    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) 
            throws IOException, ServletException {
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        HttpServletResponse httpResponse = (HttpServletResponse) response;
        HttpSession session = httpRequest.getSession(false); // Don't create new session if one doesn't exist

        String path = httpRequest.getRequestURI().substring(httpRequest.getContextPath().length());

        // Allow access to excluded URLs
        if (EXCLUDED_URLS.contains(path)) {
            chain.doFilter(request, response);
            return;
        }

        boolean loggedIn = (session != null && session.getAttribute("userId") != null);

        if (loggedIn) {
            // Set user attributes for JSP access
            request.setAttribute("userId", session.getAttribute("userId"));
            request.setAttribute("userRole", session.getAttribute("userRole"));
            request.setAttribute("loggedInUser", session.getAttribute("loggedInUser"));
            chain.doFilter(request, response);
        } else {
            httpResponse.sendRedirect(httpRequest.getContextPath() + "/login.jsp");
        }
    }

    // Other filter methods (init, destroy) omitted for brevity
}
```

**`web.xml` Configuration:**

This configuration registers the `AuthFilter` and maps it to all `.jsp` files, ensuring that every JSP request goes through the filter.

```xml
<filter>
    <filter-name>AuthFilter</filter-name>
    <filter-class>com.academic.filters.AuthFilter</filter-class>
</filter>
<filter-mapping>
    <filter-name>AuthFilter</filter-name>
    <url-pattern>*.jsp</url-pattern>
</filter-mapping>
```
