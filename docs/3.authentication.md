# Project Demonstration Notes: User Authentication and Password Hashing

## Key Feature: User Authentication and Password Hashing (BCrypt)

*   **Demonstration:** Log in with different user roles. Show the login process and mention the security aspects of password handling.
*   **Underlying Mechanism:** User passwords are not stored in plain text. Instead, they are hashed using the BCrypt algorithm, making them secure against brute-force attacks and database breaches. The `PasswordUtil.java` class (or similar utility) handles the hashing and verification process.

#### Technical Details: `PasswordUtil.java` (Conceptual Snippet)

```java
// This is a conceptual representation. Actual implementation might vary.
// The project uses at.favre.lib.crypto.bcrypt.BCrypt for hashing.

public class PasswordUtil {

    public static String hashPassword(String password) {
        return BCrypt.withDefaults().hashToString(12, password.toCharArray());
    }

    public static boolean verifyPassword(String password, String hashedPassword) {
        return BCrypt.verifyer().verify(password.toCharArray(), hashedPassword.toCharArray()).verified;
    }
}
```
