# Project Demonstration Notes: Dynamic Content Rendering with JSP

## Key Feature: Dynamic Content Rendering with JSP

*   **Demonstration:** Show how different parts of the application's UI (e.g., dashboard widgets, navigation menus, user-specific data) change based on the logged-in user's role and retrieved data.
*   **Underlying Mechanism:** JSP (JavaServer Pages) is used to embed Java code directly within HTML. This allows for server-side rendering of dynamic content. Conditional logic (`<% if (...) %>`), loops (`<% for (...) %>`), and expressions (`<%= ... %>`) are used to tailor the HTML output before it's sent to the client.

#### Technical Details: `dashboard.jsp` and `includes/header.jsp` (Conceptual Snippets)

**Role-based content in `dashboard.jsp`:**

```jsp
<div class="summary-cards-grid">
    <% if ("Admin".equals(userRole)) { %>
        <div class="summary-card"><h3>Admin Overview</h3><p>System-wide statistics...</p></div>
    <% } else if ("Parent".equals(userRole)) { %>
        <div class="summary-card"><h3>Welcome, <%= parentName %>!</h3><p>Here's a quick overview of your student's academic status.</p></div>
    <% } %>
    <!-- ... other roles ... -->
</div>
```

**Dynamic navigation in `includes/sidebar.jsp`:**

```jsp
<% String currentPage = request.getParameter("activePage"); %>
<nav class="sidebar">
    <ul class="nav-menu">
        <li><a href="dashboard.jsp" class="<%= "dashboard".equals(currentPage) ? "active" : "" %>"><i class="fas fa-home"></i> Dashboard</a></li>
        <% if ("Admin".equals(userRole) || "Teacher".equals(userRole)) { %>
            <li><a href="course_management.jsp" class="<%= "courses".equals(currentPage) ? "active" : "" %>"><i class="fas fa-book"></i> Courses</a></li>
        <% } %>
        <!-- ... other dynamic links ... -->
    </ul>
</nav>
```
