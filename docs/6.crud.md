# Project Demonstration Notes: Database Interaction (CRUD Operations)

## Key Feature: Database Interaction (CRUD Operations)

*   **Demonstration:** Showcase various pages where users can create, read, update, and delete data. Examples include:
    *   **Create:** Registering a new user, adding a new course.
    *   **Read:** Viewing student profiles, course lists, attendance records.
    *   **Update:** Updating a user's profile, changing grades, marking attendance.
    *   **Delete:** Deleting a course, deleting a message.
*   **Underlying Mechanism:** All CRUD operations are performed directly within JSP scriptlets using `java.sql.Connection`, `java.sql.PreparedStatement`, and `java.sql.ResultSet`. Prepared statements are used universally to prevent SQL injection vulnerabilities.

#### Technical Details: Example CRUD Operations

**1. Reading Data (e.g., Fetching messages in `messages.jsp`):**

```jsp
<% 
    // ... connection setup ...
    PreparedStatement pstmt = null;
    ResultSet rs = null;
    String sql = "";

    if ("inbox".equals(currentView)) {
        sql = "SELECT m.MessageID, m.SenderUserID, m.ReceiverUserID, s.Username AS SenderUsername, r.Username AS ReceiverUsername, m.Subject, m.Content, m.Timestamp, m.IsRead " +
              "FROM Messages m " +
              "JOIN Users s ON m.SenderUserID = s.UserID " +
              "JOIN Users r ON m.ReceiverUserID = r.UserID " +
              "WHERE m.ReceiverUserID = ? AND m.DeletedByReceiver = FALSE ORDER BY m.Timestamp DESC";
    } else { // sent view
        sql = "SELECT m.MessageID, m.SenderUserID, m.ReceiverUserID, s.Username AS SenderUsername, r.Username AS ReceiverUsername, m.Subject, m.Content, m.Timestamp, m.IsRead " +
              "FROM Messages m " +
              "JOIN Users s ON m.SenderUserID = s.UserID " +
              "JOIN Users r ON m.ReceiverUserID = r.UserID " +
              "WHERE m.SenderUserID = ? AND m.DeletedBySender = FALSE ORDER BY m.Timestamp DESC";
    }

    try {
        pstmt = conn.prepareStatement(sql);
        pstmt.setInt(1, userId);
        rs = pstmt.executeQuery();
        while (rs.next()) {
            // ... process results and display ...
        }
    } catch (Exception e) {
        // ... error handling ...
    } finally {
        // ... close resources ...
    }
%>
```

**2. Creating Data (e.g., Registering a new user in `register_process.jsp`):**

```jsp
<%

    PreparedStatement pstmt = null;

        pstmt = conn.prepareStatement(sql);

        // ... error handling ...

        // ... close resources ...

%>
```
